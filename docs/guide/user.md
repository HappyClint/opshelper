# opshelper 用户手册

opshelper 以对话为主工作区。每位用户使用自己的固定 OpenCode 运行环境、个人文件和个人定时任务；管理员可分配智能体，你也可以在“智能体目录”创建新的智能体。同一用户获配的智能体可以在一次任务中协作，它们共享该用户的工作目录。系统不提供项目、多人共享文件或共享任务。

## 登录与工作区

打开管理员提供的地址，使用账号和密码登录。登录后进入 `/gateway/chat`。左侧上方是已分配的智能体、搜索与会话列表，`新建会话`下方的“智能体目录”“定时任务”“我的文件”快捷入口打开对应的独立页面；会话较多时列表默认只列出最近若干条，用列表末尾的“显示更早的 N 条会话”展开全部。窄屏时用左上角菜单打开侧栏。

如果页面提示“管理员尚未给你分配智能体”，请联系管理员完成分配并等待运行环境显示“已就绪”。你也可以在“智能体目录”创建智能体；保存后系统会自动分配给你并更新运行环境。你创建的智能体仅自己可见，可在目录中继续编辑或删除；管理员分配的智能体可查看和使用，但不能由你修改或删除。

聊天侧栏底部可退出登录。点底部的用户名进入“个人设置”（`/gateway/user`），可查看个人容器并修改密码；新密码至少 6 位。

## 对话

1. 在左侧选择主智能体。选择智能体时会打开它最近的一条对话；点“新建会话”可开始新会话。
2. 在输入框写清目标、范围、输入和期望输出。可以直接拖入文件、点回形针上传，或输入 `@` 选择“我的文件”中的现有文件。
3. 如有多个模型，发送前可在输入区切换；所选模型只对之后提交的任务生效。无人值守或已确认任务范围时，也可开启“自动授权”；该选择会应用到本条及之后发送的消息。
4. 点发送。用户已有任务运行时，新任务进入该用户自己的队列；不同用户使用各自的运行环境。

新会话默认提供“帮我整理资料”“帮我润色文字”“帮我制定计划”三个通用示例。点击后只填入草稿，补充资料或目标后再发送；已有草稿会保留，示例追加在后面。管理员在智能体配置中提供了示例时，优先显示配置的内容。

页面会显示排队、建立连接、处理中、等待输入、完成、失败、取消或“状态无法确认”。主智能体调用其他已分配智能体时，输入框上方（分割线以上）会固定显示默认折叠的“协作过程”，展开可查看状态和排障编号。

智能体实际使用工具时，回答卡片会显示系统根据运行事件生成的“操作记录”，不依赖模型自行回忆。默认只显示“查看、搜索、修改、命令、联网、扩展、技能、协作”等分类和次数；展开后可查看每一步的对象、状态和结果数量，再展开“调用详情”可查看工具标识、参数和输出。重复读取不会混入回答正文。修改文件、执行命令、外部访问和工作区外路径会以醒目标记显示；失败记录会自动展开。模型推理和技能说明不会展示，密码、令牌等敏感参数会隐藏。

“技能”只有在运行时确实出现技能工具调用时才标为“使用技能”；系统不会把智能体配置中仅仅可用、但本轮未调用的技能称为“已使用”。默认情况下，需要授权的修改、命令或外部访问会继续使用单独的确认卡片，只能“允许一次”或“拒绝”。开启“自动授权”后，平台会为该次执行及其协作智能体自动选择“允许一次”，不会写入永久允许规则；智能体主动提问仍需人工回答。

执行中仍可继续发送，新任务会排队。点停止只处理当前执行。运行环境的停止、重启或重建在执行中和待恢复时会被拒绝。

智能体提问时，按卡片要求选择或填写答案并提交。工具需要确认时只能“允许一次”或“拒绝”，没有永久允许。自动授权是每次执行的快照：消息发出后再切换开关，不会改变已经排队或运行中的执行。长时间不处理时，执行会按部署设置超时。

出现“执行状态无法确认，工作台已暂停”时，先点“重新核对状态”。在核对完成前不要用改写后的内容重复提交；同样内容在网络恢复后再次发送会沿用原请求标识进行核对。

对话列表中的叉号执行“归档对话”，不会回退或删除工作目录里的文件；归档只是从列表隐藏，带链接（例如定时任务结果里的“打开完整对话”）仍可打开，在里面再次发言会让它回到列表。“从这里重新开始”会新建对话并复制该条用户消息到输入框，也不会回退文件。

## 附件与我的文件

聊天顶部文件按钮和输入框回形针只用于添加本次输入附件。需要整理文件时进入 `/gateway/files` 的“我的文件”。完整文件管理支持：

- 新建文件和文件夹，上传文件和文件夹；
- 展开目录、刷新、显示隐藏文件；
- 预览图片、PDF、Markdown、HTML 和常见文本，编辑并保存文本；
- 下载、复制相对路径、重命名或移动；
- 多选移动或删除。

上传接口当前限制单个文件不超过 10 MiB；文本读取和保存限制 2 MiB。其他不可预览格式仍可下载。若保存时提示文件已被其他进程修改，先核对新内容；再次点保存会用当前编辑内容覆盖文件。

删除文件或文件夹不可恢复，删除文件夹会递归删除其内容。智能体和用户操作使用同一 workspace，编辑文件时可能发生并发修改。

## 个人定时任务

可从聊天输入区点“设为定时”，把当前草稿、主智能体、模型和附件带入新任务；也可在 `/gateway/schedules` 点“新建任务”。聊天草稿不会因进入定时任务页面而提交为对话。

创建时填写任务名称和能独立理解的任务说明，再选择主智能体、可选协作智能体、输入文件和时间。无人值守任务可开启“自动允许工具授权”：每次运行会自动允许本次工具请求，包含协作智能体的请求，但不会自动回答智能体提问。该设置会随任务保存，修改只影响修改后登记的新执行。执行频率支持：

- 一次：选择未来日期和时间；
- 每天：选择时间；
- 每周：选择星期和时间；
- Crontab：填写标准 5 段表达式（分、时、日、月、周），例如 `0 9 * * 1-5` 表示工作日 09:00。

所有计划固定使用 `Asia/Shanghai`（北京时间）。Crontab 表达式同样按北京时间解释；不支持自定义时区、共享计划或外部通知。

平台不会要求普通对话或定时任务自动生成文件。需要定时任务交付文件时，在任务说明中明确文件要求，并用 `{{output_dir}}` 表示本轮结果目录，例如“生成报告并保存到 `{{output_dir}}/report.md`”。运行时平台只替换该变量并为本轮准备结果目录；未使用变量时不会追加输出目录说明或创建执行结果目录。没有生成文件的空结果目录会在执行结束时清理。

任务详情可编辑、暂停、恢复、立即运行或删除。暂停会取消尚未开始的该计划执行，暂停状态不能立即运行。已完成的一次任务可编辑执行时间后再次启用。删除会移除任务配置及定时任务页中的执行记录，但保留已生成的对话和文件；任务仍在排队、执行、等待输入或状态待核对时不能删除。

执行记录最多展示最近 100 次，包含计划时间、实际开始/结束时间、状态、错误、计划所需智能体、实际协作智能体和输出文件。点“查看结果”会直接弹出本次执行返回的回答（失败或跳过时显示原因），回答按对话页的规则重新读取，不含模型推理内容；运行环境暂时读不到时会显示执行当时保存的结果。需要全文时可从弹窗打开完整对话。点输出文件会在“我的文件”中定位并在支持时预览。

定时任务遵循以下规则：

- 到点后由 worker 登记，实际执行仍进入个人顶层队列，并按需唤醒同一个固定容器；
- 按当前默认配置，晚于计划时间超过 2 分钟的漏点记为“已跳过”，不补跑；
- 同一计划上一次执行仍未结束时，本次记为“已跳过”，避免积压；
- 所需智能体被撤销、停用或检查失败时，计划自动暂停，尚未开始的相关执行会取消；
- 配置冻结时，本次会跳过并暂停计划；恢复前需要管理员处理运行环境。

## 个人运行环境

设置页可查看自己的容器状态并执行启动、停止和重启。聊天和定时任务通常会按需启动已停止的容器；未勾选“保持容器运行”的容器空闲达到部署阈值后会由 worker 停止，个人文件和会话 state 保留。

有执行正在运行、等待输入或等待恢复时，先在对话中处理或停止执行，再操作容器。停止与重启会中断 OpenCode 进程，但不会删除个人 workspace 或 state。
